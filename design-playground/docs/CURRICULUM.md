# Curriculum Specification — DESIGN TO UI/UX

**Total Structured Modules:** 07 (`M01 – M07`) across Two Foundational & Tool Phases + Phase 03 Practical Application.

---

## Phase 01 — THINK VISUALLY (Morning Sessions)

### Module 01: Introduction to Design (`09:20 – 09:50`, 30 min)
- **Objective:** Understand design as visual communication and problem solving.
- **Topics:** What is design, Design vs. Art, Visual Communication, Design as Problem Solving, Understanding Target Audience, Design Process (`Understand -> Explore -> Create -> Review`).
- **Interactive:** Communication Effectiveness Analyzer (`Poster A` uniform clutter vs. `Poster B` intentional rank).
- **Checkpoint:** Separate surface decoration from goal-driven visual communication.

### Module 02: Elements of Design (`09:50 – 10:15`, 25 min)
- **Objective:** Identify the fundamental visual elements used to construct a layout.
- **Topics:** Line, Shape, Form, Color, Texture, Space (positive & negative), Value contrast.
- **Interactive:** Visual Composition Lab (`Add Circle/Square/Line`, position X/Y, scale, rotation, opacity value).

### Module 03: Principles of Design (`10:15 – 10:30`, 15 min)
- **Objective:** Understand how visual elements organize into effective compositions.
- **Core Emphasis (`3.1 – 3.5`):** **Contrast, Balance, Visual Hierarchy, Alignment, Proximity**.
- **Supporting Principles (`3.6 – 3.9`):** Emphasis, Repetition, Rhythm, Unity.
- **Interactive:** Before & After Principles Transformation Switchboard.

*Morning Break (`10:30 – 10:45`, 15 min)*

### Module 04: Typography & Color Theory (`10:45 – 11:20`, 35 min)
- **Objective:** Understand how typography spacing and contextual color choices drive visual communication.
- **Typography Topics:** Typeface vs. font, anatomy basics, Serif / Sans Serif / Display traits, font weight/size/letter spacing/line height, pairing, readability & legibility.
- **Color Topics:** Color wheel, primary/secondary, warm vs. cool, complementary & analogous harmony, WCAG luminance contrast, and **contextual color perception** (explicitly avoiding rigid claims like "blue always equals corporate").
- **Interactive:** Typography Playground + Color Exploration & WCAG AA/AAA Checker.

### Module 05: Layout & Composition (`11:20 – 11:45`, 25 min)
- **Objective:** Understand how elements structure cleanly using grids and Swiss Editorial discipline.
- **Topics:** Layout role, Margins / Padding / Columns / Gutters / Alignment, Whitespace & rhythm, Z-pattern vs. F-pattern scanning, Hero section vs. Poster composition, **Introducing Swiss Editorial Design** (explicitly highlighting clarity, mathematical grids, asymmetry, and vibrant color usage rather than monochrome stereotypes).
- **Interactive:** Multi-color Swiss Editorial Specimen Wall (with toggleable 6-Col grid) + Interactive Grid Sandbox.

*Lunch Break (`11:45 – 12:30`, 45 min)*

---

## Phase 02 — LEARN THE TOOLS (Early Afternoon Sessions)

### Module 06: Figma Essentials (`12:30 – 13:05`, 35 min)
- **Objective:** Operate Figma confidently to build shapes, text, frames, and exportable files.
- **Topics:** Workspace Anatomy (Toolbar, Layers, Assets, Canvas, Properties, Pages), Frames (`F`) vs. Groups (`Ctrl/Cmd+G`), Vector & Shape tools (`R`, `O`, `P`), Text (`T`), Fill/Stroke/Effects, Alignment, Export (`PNG 2x / JPG / SVG / PDF`), and **8 Core Shortcuts (`V, F, R, O, T, P, Shift+A, Ctrl/Cmd+G`)**.
- **Interactive:** Interactive Figma Workspace Hotspot Inspector + Shortcut Filter Grid.

### Module 07: Figma for Interface Design (`13:05 – 13:40`, 35 min)
- **Objective:** Apply beginner Figma UI features to design structured interface components.
- **Topics:** Frames as viewport containers, Auto Layout basics (`Shift + A` direction, gap, padding), Components basics (Main Component + Instances), Beginner Resizing (`Hug` vs. `Fill` vs. `Fixed`), 8px spacing rhythm, Basic click-to-navigate Prototyping, and Previewing at 100% scale inside Present (`▶`) mode.
- **Hands-On Interactive:** **Mini Figma Exercise** (`1 Frame Container + 1 Headline + 1 Subheading + 2 Geometric Shapes + 1 CTA Button` with live requirement checks & SVG export).
